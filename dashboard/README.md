# Dashboard Data

The files in `dashboard/data/` are generated by the ETL pipeline and are ready to import into Power BI or Tableau Public. `sales_detail.csv` is regenerable and is not committed to Git.

## File Reference

| File | Columns | Meaning |
|---|---|---|
| `kpi_summary.csv` | `kpi_name`, `kpi_value`, `kpi_unit` | One row per executive KPI. Use `kpi_name` to select a card and `kpi_unit` for labeling. |
| `monthly_revenue.csv` | `year`, `month`, `month_name`, `year_month`, `revenue`, `orders`, `average_order_value`, `mom_growth_pct` | Complete monthly revenue trend, one row per month. |
| `monthly_delivery.csv` | `year_month`, `delivered_items`, `late_items`, `late_delivery_rate_pct`, `average_delivery_days`, `average_review_score` | Monthly delivery performance and review context for complete trend months. |
| `category_revenue.csv` | `category`, `revenue`, `items`, `orders`, `revenue_share_pct` | Revenue and item volume aggregated by translated product category. |
| `customer_state_revenue.csv` | `customer_state`, `revenue`, `orders`, `items` | Revenue and item volume aggregated by customer state. |
| `delivery_by_state.csv` | `seller_state`, `delivered_items`, `late_items`, `late_delivery_rate_pct` | Seller-state delivery performance subject to the configured minimum delivered-item threshold. |
| `review_summary.csv` | `summary_type`, `review_score`, `category`, `review_count`, `average_review_score`, `share_pct` | Mixed review distribution and category-average rows; filter by `summary_type` before using it. |
| `payment_mix.csv` | `payment_type`, `payment_value`, `payment_share_pct` | Payment value and share by payment type. |
| `sales_detail.csv` | `order_id`, `order_item_id`, `purchase_date_key`, `purchase_timestamp`, `order_status`, `customer_id`, `customer_unique_id`, `customer_state`, `product_id`, `product_category_name`, `category`, `seller_id`, `seller_state`, `price`, `freight_value`, `total_item_value`, `revenue`, `revenue_eligible`, `delivery_days`, `delivery_delay_days`, `is_late` | Regenerable item-level detail for ad hoc filtering and repeat-customer calculations. It is intentionally excluded from Git. |

## Regenerate

From the project root:

```powershell
python -m src.run_pipeline
```

Use `python -m src.run_pipeline --sample` only to regenerate isolated sample outputs. Check all exports with:

```powershell
python -m src.check_dashboard_data
```

## Applied Data Rules

- Canceled and unavailable orders are excluded from revenue and eligible order/item measures.
- Dashboard trend exports exclude 2016 and the latest incomplete month.
- `delivery_by_state.csv` requires at least `MIN_DELIVERED_ITEMS_PER_STATE` delivered items; `review_summary.csv` requires at least `MIN_REVIEWS_PER_CATEGORY` reviews per category.
- Revenue is stored as plain decimal numbers in BRL, without currency symbols or thousands separators.
- Month fields use `YYYY-MM`; timestamps and dates use ISO-compatible text.
